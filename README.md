# TaskSpace

Aplicación de gestión de tareas con recordatorios por notificación y email. Construida con JS + Firebase.

## 🔧 Requisitos

- Node.js 18+
- Cuenta Firebase con Firestore, Auth, Functions, Messaging habilitados

## 🚀 Instalación

```bash
git clone https://github.com/tuusuario/taskspace-ok.git
cd taskspace/web
npm install
cd ../functions
npm install
